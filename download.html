Quick Setup Guide

Step 1

1. Download Package

Get the latest .rbxl (Place file) or .rbxm (Model file) from GitHub Releases.

Step 2

2. Open in Studio

Open Roblox Studio, create or open your experience, and import the downloaded package into StarterGui.

Step 3

3. Run & Test

Press F5 (Play) in Roblox Studio to test, or publish to Roblox to share with your friends and community!

Roblox Requirements

Roblox Client

Valid Roblox account and client to run the experience.

Roblox Studio

Roblox Studio installed if you want to inspect or modify source code.

Network Connection

Stable connection for downloading cloud assets and multiplayer syncing.

Hardware Requirements

CPU Architecture

64-bit x86_64 or ARM64 Dual Core processor (1.5 GHz+).

RAM & Storage

Minimum 2 GB RAM (4 GB recommended), 10 GB free disk space.

Display & Graphics

1024x768 or higher display resolution with standard OpenGL/Vulkan support.
