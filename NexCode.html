Features

Everything you need, nothing you don't

A complete development environment in a single lightweight desktop app.

Monaco-powered Editor

  • Syntax highlighting, IntelliSense, parameter hints, folding, multi-cursor
  • TypeScript, JavaScript, Python, C/C++, HTML, CSS, JSON, Markdown, Lua, Go, Rust and HOSC/HOSC++
  • Split editor, drag-and-drop tabs, regex find & replace
  • Invisible Unicode detector against Trojan Source attacks

Markdown Live Preview

  • Full-width preview with instant synchronization
  • LaTeX math, Mermaid diagrams, GFM task lists and tables
  • Syntax-highlighted code blocks with one-click copy
  • Quick switch between source and preview

Integrated Terminal

  • Multi-session xterm.js terminal: bash, zsh, cmd, PowerShell
  • Ligatures, Unicode 11, Fit and Clipboard addons, clickable URLs
  • Shell quick-switcher and toggleable panel

AI Assistant & IDE Agent

  • Dedicated AI agent panel with chat interface for interactive coding help
  • Gemini AI diff review: inline reviews, explanations and refactoring suggestions

Git & Source Control

Built-in Git panel: unstaged/staged changes, inline diff viewer, stage/unstage files, commit messages and branch status.

Run & Debugger

  • One-click run with F5 directly in the terminal
  • Breakpoints, step execution, call stack and live variable watch

Extensions & Themes

  • Extension marketplace via the Open VSX registry
  • HSIXET theme engine with the custom .hsiext format for UI palettes and editor color schemes

Built-in Viewers & Web Preview

  • PDF viewer with no external dependencies
  • Browser preview in an iframe with responsive simulation
  • Media viewer for images, video and audio

Easter Eggs & Moments

Interactive chibi characters (Shiroko, Hoshino, Momoi) and audio moments that bring personality to your coding sessions.

Getting Started

Run from source

Three commands from clone to a running editor with hot reload.

Requires Node.js 20.x+ npm (bundled with Node.js) git
1Clone the repository
git clone https://github.com/Hyggshi-OS-project-center/NexCode.git && cd NexCode
2Install dependencies
npm install
3Start development mode
npm run dev

npm run dev launches the Vite renderer server together with Electron. Need hardware recommendations or troubleshooting? See BUILD.md.

Architecture

Tech stack & architecture

A clean split between the Electron main process and a Vite-powered renderer.

Main Process

Node.js + Electron API
  • App lifecycle & window management
  • IPC handlers & PTY (node-pty)
  • File system & dialogs
  • Auto-update service
  • External protocol safety

Renderer Process

Vite + TypeScript + DOM
  • Monaco Editor engine
  • UI shell & tabs system
  • xterm.js terminal panel
  • Markdown & PDF viewers
  • AI agent & Git panels
⇄ IPC bridge between main and renderer
